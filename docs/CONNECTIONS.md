# 模型连接

在 Inthes 的「连接与偏好」中添加连接，然后在对话页选择要使用的连接和模型。可以使用账户连接，也可以输入自己在模型服务商取得的 API Key。

| 连接 | 设置方式 | 主要用途 |
| --- | --- | --- |
| ChatGPT 账户 | 登录本机 Codex 组件 | 论文阅读、文献分析、联网检索、图片生成 |
| Antigravity 账户 | 登录本机 Antigravity 组件 | 论文阅读、文献分析、联网检索 |
| DeepSeek、OpenRouter、OpenAI、Anthropic、Gemini | 填写对应 API Key | 使用所选模型阅读和分析文献 |
| Qwen、Kimi、GLM、MiniMax | 填写对应平台的 API Key | 使用所选模型阅读和分析文献；可按服务能力配置联网检索 |
| 自定义 API | 填写兼容协议的服务地址、Key 和模型 | 接入其他模型服务 |

添加连接后可以获取模型列表并测试连接。若服务未提供模型列表，界面允许手动填写模型 ID。模型的工具调用、视觉输入、联网检索及推理参数取决于连接和所选模型；相关选项集中在连接的「高级参数」中。

Qwen 和 MiniMax 提供按量付费及 Token Plan 连接选项。支持额度或余额查询的连接会在对话状态栏显示可用信息；其他 API 可以在「高级参数」中配置服务商提供的余额查询接口。具体价格、套餐和使用额度请以服务商账户为准。

如果希望检索论文并导入 Zotero 分类，请使用账户连接，或在具备原生联网能力的 API 连接中启用「联网检索」。模型会根据你的问题选择是否检索。
