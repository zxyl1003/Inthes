Inthes 首个公开测试版，面向 Zotero 10。

- 在 Zotero 侧栏对单篇论文或最多 5 篇选中文献提问，引用可预览原文并跳转 PDF 页码。
- 选择分类或子分类进行文献库问答与逐篇分析，范围上限 200 篇，并显示每篇进度、来源及失败项。
- 默认使用 Zotero 本地文字；可选 MinerU 增强解析表格、公式与图片。
- 支持 ChatGPT、Antigravity 账户及多家模型 API；可按连接能力使用原生联网论文检索与分类导入。
- 支持会话历史、归档、保存 Zotero 笔记，以及 Markdown、JSON、PDF、Word 导出。

下载下方的 `inthes-0.10.48.xpi`，在 Zotero 的「工具 → 插件」中安装。使用方法、服务费用和隐私说明见 [使用指南](https://github.com/zxyl1003/Inthes/blob/main/docs/USER_GUIDE.md)。

此前本地测试包使用 `folio@zotero.local` 插件 ID；安装公开版前请先卸载旧包。公开版 ID 固定为 `inthes@zxyl1003.github.io`，以 GitHub Release 和本仓库 `updates.json` 提供后续更新。
