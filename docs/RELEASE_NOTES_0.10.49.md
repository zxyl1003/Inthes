Inthes 0.10.49 修复了首个公开版本的依赖锁文件，使 GitHub CI 与从零构建能够正确安装 `fflate`。插件功能与 0.10.48 相同。

下载下方的 `inthes-0.10.49.xpi`，在 Zotero 10 的「工具 → 插件」中安装。完整功能、连接设置、外部服务费用和隐私说明见 [使用指南](https://github.com/zxyl1003/Inthes/blob/main/docs/USER_GUIDE.md)。

此前本地测试包使用 `folio@zotero.local` 插件 ID；安装公开版前请先卸载旧包。公开版 ID 固定为 `inthes@zxyl1003.github.io`。
