# Inthes 使用指南

Inthes 是 Zotero 的论文阅读侧栏，让提问、原文核查、文献库分析和笔记留在同一处。它围绕**可追溯来源**工作：回答中的本地文献引用可预览对应原文，并跳回 PDF 页码。它不替代人工核查，尤其不能保证联网检索结果或模型推断一定正确。

## 安装与开始

1. 从 [GitHub Releases](https://github.com/zxyl1003/Inthes/releases) 下载最新的 `inthes-<版本>.xpi`。
2. 在 Zotero 中打开「工具 → 插件」，把 XPI 拖入插件窗口安装；重新打开 Zotero 后，在工具栏点击 **Inthes**。目前公开版本面向 Zotero 10；其他版本以对应 Release 标注的实测范围为准。
3. 进入「连接与偏好」添加连接。可以使用 ChatGPT 账户、Antigravity 账户，或配置自己的模型 API Key。账户模式需要相应的官方本地组件；API 模式按服务商计费。Inthes 不提供模型额度或 MinerU 额度。
4. 在 Zotero 中选中论文或打开 PDF，然后在侧栏提问。首次提问时才会按需读取文献。

曾安装过插件 ID 为 `folio@zotero.local` 的本地测试包时，请先在 Zotero 插件窗口卸载旧包，再安装公开版；插件 ID 已固定为 `inthes@zxyl1003.github.io`，旧包不能通过自动更新变成新 ID。重要会话建议先导出备份。

> 配图待补：安装入口与首次添加连接的两张截图；不要拍摄 API Key、授权码或账户邮件地址。

## 阅读当前论文

「阅读」页自动跟随当前选中的文献。发送第一条消息后，文献范围固定；要换论文，请新建对话。这里最多同时阅读 5 篇文献。模型可以根据问题调用可用的论文工具，查找相关原文并回答，也可以使用总结入口对全文做分段阅读。缺少 PDF 时，只能依据 Zotero 条目摘要并注明证据范围。

回答中的本地来源标记由插件对应到文献和 PDF 页码：悬浮查看引用片段，点击可跳回原文。界面末尾的「本次检索 X / Y 个来源片段」表示本轮使用的片段覆盖量，不等同于逐页核查全文。无法识别的来源标记会提示错误，不会伪装成可点击引用。

## 文献库阅读与批量分析

「文献库」页可以选择分类、包含子分类，或使用当前选中的文献。按 Zotero 主条目去重后，范围最多 200 篇；超过上限需缩小范围。仅选定范围时先读取条目元数据，不会立刻把全部 PDF 上传到 MinerU 或发送给模型。

直接提问即可。模型可以选择检索元数据与已有全文索引、读取指定原文，或对整个范围逐篇核查并汇总。要求全面分析时，Inthes 会并发解析、逐篇提取、分层汇总；进度页显示每篇的原文状态、核查状态与失败原因。可暂停、继续或重试；继续同一任务会保留已完成结果。不同问题或不同模型可能需要新的逐篇分析，已缓存的解析结果仍可复用。

回答会说明实际处理范围；文献失败时显示失败项，并基于成功处理的证据回答。200 篇是选择上限，不代表一次请求把 200 篇全文塞入上下文。较大的任务会花费更长时间并消耗更多服务额度。

> 配图待补：文献库范围选择、文献与进度列表、带来源的综合回答各一张；使用小规模演示分类。

## 文献解析与图片

默认使用 Zotero 本地提取的文字和全文索引。扫描 PDF 如未先做 OCR，本地提取可能没有足够文字。在「连接与偏好 → 偏好 → 文献解析」开启 MinerU 后，**需要解析且没有有效缓存的 PDF** 会上传至 MinerU；其结果可提供段落、表格、公式与图片。设置页可选择解析模式、语言、OCR，以及文献库任务使用的 MinerU 并发。MinerU 的 Token 和费用由用户自己管理。

可以向支持视觉输入的模型粘贴图片。ChatGPT 账户返回的生成图片可预览、复制或另存为；其他连接的图片生成能力以界面提示为准。历史记录中的图片保存在本机；把回答或完整会话保存为 Zotero 笔记时，图片会写入笔记附件。

> 配图待补：文献解析设置和一条包含图片、公式、表格的回答；图片应来自可公开展示的测试资料。

## 论文检索与导入

ChatGPT 与 Antigravity 账户连接可按问题选择联网论文检索工具；部分 API 连接也能在高级设置开启其**服务商原生**联网能力。可明确要求检索并导入某个现有 Zotero 分类。插件通过 DOI／arXiv 信息核验候选论文，按 DOI、arXiv ID、标题、作者与年份在目标文库内去重；已有条目只加入分类，疑似重复不会自动合并。它不自动创建分类或下载 PDF。搜索覆盖范围取决于所选服务，不能保证穷尽。

对于当前论文的问答，应优先以本地原文引用判断答案。联网来源以网页链接呈现，与可跳转的本地 PDF 引用区分。

> 配图待补：检索并导入已有分类的完整对话，展示核验结果和去重结果；隐藏个人文库信息。

## 对话、笔记与导出

顶部「历史」可打开以往会话。右键会话可重命名、置顶、归档、导出、复制 Markdown，或将完整会话保存为 Zotero 笔记；归档页可以批量导出或删除。回答下方的「保存为笔记」只保存**当前一轮提问与回答**，历史菜单的「保存完整会话为笔记」保存整段会话。两者都尽量保留图片、公式、表格和引用。

单篇会话的笔记附在对应文献下，多篇会话生成关联来源的独立笔记。导出格式包括 Markdown、JSON、PDF、Word；JSON 可包含处理状态与本机路径，分享前请检查。删除插件缓存不会删除已保存的 Zotero 笔记及其图片附件。

> 配图待补：历史会话右键菜单与一份保存后的 Zotero 笔记，显示表格、公式和图片。

## 连接与费用

内置连接入口包括 ChatGPT 账户、Antigravity 账户、DeepSeek、OpenRouter、OpenAI、Anthropic、Gemini、Qwen、Kimi、GLM 和 MiniMax API，以及可填写端点的自定义 API。不同服务对工具调用、联网、视觉输入、图片生成、推理强度和余额查询的支持不同；界面按连接显示当前可用设置。Qwen 与 MiniMax 提供相应的按量或 Token Plan 选项。第三方服务的费用、套餐限制和服务条款由服务商决定。

聊天输入框下方显示已用／总上下文；有官方数据时，还显示账户 5 小时或周额度、API 可用余额及重置时间。无法查询的余额不会被当作零或满额。需要代理时，账户组件会读取用户 Codex 目录 `.env` 中的代理变量，详情见 [项目技术说明](../README.md)。

## 数据与隐私

- Inthes 的对话、设置和解析缓存保存在本地 Zotero 配置目录或用户指定位置；API Key 使用 Zotero 凭据管理器。
- 使用模型时，提问、选取的文献证据和必要图片会发送给所选模型服务。开启 MinerU 后，待解析的 PDF 会发送给 MinerU。只有发起联网检索时才向相应服务发送检索请求。
- Inthes 不运行开发者维护的账户服务器，也不向开发者收集个人文献或登录凭据。第三方服务的保存和处理规则应查看各自条款。
- Zotero 插件对文库有较高权限。建议从本项目 GitHub Release 下载，并检查安装包版本和更新来源。

## 常见问题

**为什么没有原文引用？** PDF 可能缺少文字层、未关联到当前条目，或模型没有提供有效的本地来源标记。扫描件可先 OCR，或按需开启 MinerU。

**为什么再次提问还会产生模型请求？** 解析缓存只复用文献提取结果。新问题可能需要重新检索、核查或总结；同问题同模型的已完成逐篇结果可复用。

**为什么某个 API 无法联网或显示余额？** 服务商、端点、模型和 Key 权限可能不同。连接页会在实际搜索失败时给出错误；余额查询仅在官方接口或用户正确配置的接口可用时显示。

**如何报告问题？** 在 [GitHub Issues](https://github.com/zxyl1003/Inthes/issues) 提供 Inthes、Zotero、操作系统和连接类型的版本信息及复现步骤；请删去 API Key、授权码、私人论文、聊天内容和本地路径。
