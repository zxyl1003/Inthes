# Inthes 使用指南

Inthes 将论文问答、文献库分析与研究记录整合在 Zotero 侧栏中。回答中的本地引用可以预览原文并跳转到 PDF 页码。

## 安装与连接

从 [GitHub Releases](https://github.com/zxyl1003/Inthes/releases) 下载最新 XPI，在 Zotero 10 的「工具 → 插件」中从文件安装。打开 Inthes 侧栏后，进入「连接与偏好」添加 ChatGPT 或 Antigravity 账户，或配置模型 API。连接方式及相关设置见[模型连接](CONNECTIONS.md)。

在对话页选择连接和模型。输入框下方可查看上下文用量；连接提供额度或余额信息时，状态栏也会显示相应数据。

## 阅读论文

在 Zotero 中选中论文或打开 PDF，切换到 Inthes 的「阅读」页，直接提问。一次可以阅读最多 5 篇文献。你可以询问方法、实验结果和局限，也可以要求总结或比较多篇论文。

回答中的本地引用显示文献和页码。将鼠标停在引用上可查看原文片段，点击可打开对应 PDF 页。回答末尾的来源片段数量反映本轮检索范围。要换一组文献，请新建对话。

可以将图片粘贴到输入框，与问题一起发送给支持视觉输入的模型。ChatGPT 账户生成的图片可点击预览，并可复制或另存为。

## 分析文献库

切换到「文献库」页，选择一个 Zotero 分类；需要时可以包含子分类，范围上限为 200 篇。选定范围后直接提问，例如：

> 这些论文主要研究了哪些问题？各自采用什么方法，还有哪些局限？

> 比较这组文献在同一数据集上的实验结果，并标出来源。

模型根据问题选择检索、阅读原文或逐篇分析。较大的分析任务会在「文献与进度」中显示每篇的状态；你可以查看结果、暂停、继续或重试。回答会标明实际处理范围，并提供可追溯的来源。

## 文献解析

Inthes 默认使用 Zotero 可读取的论文文字。在「连接与偏好 → 偏好 → 文献解析」中可以启用 MinerU，以处理表格、公式、图片和需要 OCR 的 PDF。解析结果会保存在本机供后续阅读使用。

在「文献库阅读」设置中，可以调整逐篇核查和 MinerU 解析的并发数量。启用 MinerU 后，需解析的 PDF 会发送给 MinerU 服务。

## 检索与导入论文

使用具备联网检索能力的连接时，可以直接提出检索请求，例如：

> 检索近三年的跨视角地理定位论文，并导入到「地理定位」分类。

Inthes 会核验找到的论文并检查 Zotero 文库中的重复条目，再将结果加入指定分类。联网来源以网页链接显示；阅读本地论文时产生的原文引用则可以跳转 Zotero PDF。有关连接能力与设置，请参阅[模型连接](CONNECTIONS.md)。

## 会话、笔记与导出

顶部的历史入口可查看和管理会话。右键会话可重命名、置顶、归档、导出、复制 Markdown，或将完整会话保存为 Zotero 笔记。归档页提供批量导出和删除。

回答下方的「保存为笔记」保存当前一轮提问与回答；历史菜单中的「保存完整会话为笔记」保存整段会话。两种笔记都保留回答中的图片、表格、公式和引用。会话还可以导出为 Markdown、JSON、PDF 或 Word。

## 数据与费用

对话、设置和解析缓存保存在本机。提问时，相关内容会发送给所选模型服务；启用 MinerU 后，需解析的 PDF 会发送给 MinerU。使用第三方模型或解析服务时，费用和数据处理规则以相应服务商为准。

遇到问题时，请在 [GitHub Issues](https://github.com/zxyl1003/Inthes/issues) 提供 Inthes 与 Zotero 版本、连接类型和复现步骤。提交截图或日志前，请移除凭据和私人文献内容。
