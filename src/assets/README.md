# Inthes brand mark

`inthes.svg` is the vector refinement of the “Between pages” concept selected on 2026-09-20. The concept was generated with the built-in image generation tool; its two offset paper forms were redrawn as simple SVG paths for small sidebar icons. The sidebar uses this asset as a mask in the active theme color; the same SVG is packaged as the add-on icon.
