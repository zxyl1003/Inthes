# Inthes

**Where papers meet ideas.** 一款嵌入 Zotero 的论文阅读与文献库分析侧栏，围绕可追溯的原文证据进行提问、逐篇核查、综合分析和笔记整理。

> 配图待补：项目主图，展示 Zotero 论文阅读界面、Inthes 侧栏、原文引用和输入框；使用可公开展示的测试文献，隐藏账户信息。

**主要功能**

- **单篇与多篇阅读：** 当前文献最多 5 篇；引用可预览原文并跳转 PDF 页码。
- **文献库问答与分析：** 选定分类或子分类，最多 200 篇；按需检索、并发解析、逐篇核查并显示来源和进度。
- **按需解析：** 默认使用 Zotero 本地文字；可选 MinerU 解析段落、表格、公式和图片，结果缓存在本机。
- **检索与导入：** 支持的连接可联网检索论文、核验书目信息并导入指定 Zotero 分类，同时检查重复。
- **保存与导出：** 保存当前问答或完整会话为 Zotero 笔记，支持图片、表格和公式；也可导出 Markdown、JSON、PDF、Word。
- **自带连接：** 支持 ChatGPT、Antigravity 账户及多家模型 API；模型费用和外部解析费用由各服务商收取。

完整操作、限制和隐私说明见 [使用指南](docs/USER_GUIDE.md)。

## 使用

从 [GitHub Releases](https://github.com/zxyl1003/Inthes/releases) 下载最新的 `inthes-<版本>.xpi`，在 Zotero 10 的「工具 → 插件」中从文件安装。点击工具栏 **Inthes**，或按 **Ctrl+Shift+F**（macOS 为 Cmd+Shift+F）打开侧栏。

如果曾安装插件 ID 为 `folio@zotero.local` 的本地测试包，先卸载旧包，再安装公开版；详见[使用指南](docs/USER_GUIDE.md)。

1. 在文库中选择一篇或多篇文献，或打开 PDF。
2. 在 Inthes 的「连接与偏好」中添加模型连接。对话页点击连接选项卡，设置页点击连接列表即可切换；编辑和保存连接不会切换当前连接（首次添加除外）。拖动选项卡可调整顺序，设置页连接列表下方也提供前后移动按钮；选择和顺序自动保存在本机。
3. 侧栏自动使用当前选中的文献，直接提问或使用总结入口；更换文献请点上方「＋」新建对话。
4. 悬浮在引用上预览原文片段，点击页码回到 PDF；需要保留时，选择「保存为笔记」。

### 国内 API 与套餐

添加连接提供 Qwen、Kimi、GLM 和 MiniMax API。百炼可选择按量付费或 Token Plan 个人/团队版，MiniMax 可选择按量付费或 Token Plan；Kimi、智谱使用开放平台 API。Kimi 和 MiniMax 自动查询可用余额，MiniMax 套餐显示 5h / week 额度。端点未提供模型列表时可手动填写模型 ID。详见 [计费、联网能力与限制](docs/api-providers-2026-09-22.md)。

### 联网检索与导入论文

使用 ChatGPT 或 Antigravity 账户连接时，可以直接输入「检索近三年的地理定位相关文献，并导入到 XX 分类」。无需先选择 PDF，也无需额外搜索 API Key。模型根据问题和上下文自主选择本地阅读、联网检索、论文核验和导入工具，可在同一轮组合使用；不依赖关键词分流，也不额外调用模型分类意图。PDF 仅在调用阅读工具或点击总结入口时解析；已有证据足够时可以直接回答。

直接 API 连接可在高级参数中选择「联网检索 → 支持联网」。已适配百炼（DashScope 或 Responses）、火山方舟（Responses）、智谱、Kimi 官方搜索接口与 MiniMax 原生工具，使用当前服务的 API Key；服务商可能单独计收搜索费用。实际可用性取决于所选模型、账户权限和服务端点。插件校验服务返回的搜索记录；不支持、限流或没有实际搜索记录时会明确报错。DeepSeek 官方 API 不支持原生联网检索；第三方转发端点不会仅凭模型名称被认定为支持。

Antigravity 在同一检索对话中复用流式进程；每轮重新核验候选论文及导入目标，不沿用上一轮的导入授权。更换模型、压缩或修改历史、切换阅读模式、中止后会按需重建。额度查询仍使用独立 CLI 进程；Windows 下首次启动和额度查询可能出现官方 CLI 引起的短暂闪窗。

账户连接使用官方组件的原生实时搜索，API 连接使用所选服务的官方搜索能力。通过 Zotero 的 DOI／arXiv 标识符解析器核验书目信息，每批最多 20 篇、本轮最多 200 篇；不能核验的结果不会导入。检索覆盖范围受网页索引影响，不保证穷尽所有相关论文。

本轮明确要求导入并指定现有分类后，模型查询分类、核验论文并直接执行，不增加重复确认。分类有歧义时才询问，例如重名时需指定「我的文库 / 地理定位」这样的完整路径。插件校验目标是本轮查询到的可写分类，并在目标文库内按 DOI／arXiv ID，以及标题、作者与年份检查重复：已有条目只加入分类，已经在分类中的跳过，疑似重复或不同发表版本不自动合并。不会覆盖已有元数据、笔记或附件，也不会自动创建分类、下载 PDF。回答末尾保留实际导入记录；停止任务后，已经完成的导入保留，再次导入会重新去重。

回答生成时仍可输入下一条问题、粘贴或移除草稿图片；完成或停止后才可发送。流式显示复用已完成段落，只更新变化的内容，并将成批到达的文字分帧呈现；保留输入光标，向上阅读历史时不自动滚回底部。

回答支持 `$…$`、`$$…$$`、`\(…\)`、`\[…\]` 形式的 LaTeX 公式，使用本地 KaTeX 转换和 Zotero 原生 MathML 显示；公式闭合后渲染，代码示例保持原样。上下文显示已用量 / 总量，以 k / m 缩写；初始已用量为 0，只在收到新的服务端 token 用量时更新，左侧圆圈按已占用比例逐步填充。尚未发送的草稿、图片、生成过程和缺失用量不会改变上次显示；缓存输入仍占上下文，历次请求用量不会累加当作当前上下文。输出预留单独用于自动压缩判断，不计作已占用。上下文窗口留空时自动读取服务或模型信息，未提供时默认 200k；手动填写则作为上限。

将剪贴板中的图片粘贴到输入框即可附加，可在缩略图右上角移除。每条最多 4 张 PNG / JPEG / WebP，单张上限 4 MB、边长不超过 8192 像素；本次请求（含未压缩历史）的图片编码总量上限 12 MB。粘贴的图片按原尺寸发送；启用 MinerU 时，文献配图会单独读取并按问题提供，保留原图，发送副本的长边上限为 2048 像素。

模型列表中的「图片」标记表示已确认支持视觉输入。优先读取 OpenRouter / Codex 等服务返回的能力。旧列表可点击「刷新列表」更新。对于未提供能力信息的 API，在连接的高级设置中按服务文档确认「图片输入（当前模型）」。能力未知或不支持时，图片保留在草稿并提示切换，禁止直接发送；不会丢弃图片后仅发送文字。

附图随本机历史保存，并在后续提问中继续发送给当前模型。历史压缩只提炼已有文字解读，并明确告诉模型原图已退出上下文；完整记录中的图片保留，需要重新核查细节时可再次粘贴。回答下方的“保存为笔记”保存该轮提问和对应回答，历史菜单中的“保存完整会话为笔记”保存全部问答；两者都保留图片、公式、表格和原文引用。图片保存为 Zotero 内嵌附件，不依赖插件缓存。不保存对话记录的会话中，请自行保留所需图片或笔记。

**Inthes. Where papers meet ideas.** 文献与灵感之间。Inthes · 专注阅读。首页内置 36 句有出处的阅读与学习名言，每次启动 Zotero 随机选择，避开上次的一句；本次启动中保持不变，点击作者可查看原文出处。

可用顶部的日夜图标快速切换主题，或在「连接与偏好 → 偏好 → 外观」选择亮色、深色、跟随系统。主题按本机保存。历史与缓存路径按需展开。

## 文献库阅读

侧栏顶部切换「阅读 / 文献库」。「阅读」直接处理最多 5 篇文献；超过时可转入「文献库」。选择 Zotero 分类或子分类，可选包含下级分类，也可以使用当前选中的文献。按主条目去重，最多 200 篇；超过上限需缩小范围，不会自动截断。对话开始后范围固定，新建对话可更换范围。

直接提问即可：模型根据问题调用检索、原文阅读、逐篇分析和历史结果工具，无需手动选择问答或综合分析模式。服务与模型必须支持原生工具调用；API 支持 Chat Completions、Responses、Anthropic 和 Gemini，ChatGPT 账户通过 Codex 动态工具、Antigravity 账户通过本机 MCP 执行同一组 Inthes 文献工具。

选择分类只读取条目元数据。检索使用标题、摘要和已有 Zotero 全文索引，不上传 PDF。需要原文时才按偏好中的解析设置读取指定论文；开启 MinerU 则上传尚无有效缓存的指定 PDF。要求逐篇或全面分析时，批量提交需要解析的 PDF（已有缓存不上传），每批最多 50 个文件，并按 MinerU 并发设置限制同时处理的文献数；完成后补入后续文献，实际批次大小随可用名额和缓存查询进度变化。每篇解析完成后立即进入核查队列，不等待其余文件。已有解析缓存按附件与解析设置复用。

「文献与进度」分别显示每篇的原文读取状态和当前问题的分析状态，可查看已完成结果、具体失败原因，暂停、继续或重试。暂停会等待当前步骤完成；停止后已完成的分段结果保留。启用本地历史保存时，重启 Zotero 后仍可继续。解析与模型核查独立运行：本地解析 / 文件上传最多 3 路，下载解包及完整缓存写入最多 2 路；MinerU 服务端并发由服务调度。在「偏好 → 文献库阅读」直接输入并发数量：核查为 1–8 的整数，默认 4；MinerU 为 1–50 的整数，默认 50。MinerU 关闭时该输入框不可用，并发设置不影响 Zotero 本地批量解析。核查遇到 429 自动降低后续并发，失败项保留供重试。单轮最多 24 次工具调用、600 次分段分析或汇总请求，达到限制后可继续任务。

逐篇分析按全文分段提炼，再分层合并结果；依据为文字、表格、公式及图注，不声称已查看未提供的原图。模型可通过原文阅读工具进一步查看相关图片（须支持视觉输入）。没有 PDF 的条目仅分析摘要并明确标注。回答显示实际处理范围与失败数量，引用可以预览原文、跳转 PDF；检索命中和部分片段阅读不代表完整核查。

已完成的同问题、同模型结果可复用；更换问题或模型会另建分析任务。附件或解析设置改变后需新建文献库对话，以免历史结论的引用被新解析结果覆盖。逐篇提取使用当前模型的 Low 推理强度；模型没有 Low 时使用支持的快速档位（例如硅基流动 DeepSeek V4 的 `none`），能力未知时沿用服务默认。最终回答保留用户的推理设置。新任务的单篇输入预算最高约 32,000 token，受模型窗口限制；普通论文尽量整篇提取，长文分段。ChatGPT 同一篇的分段复用独立会话，接近窗口上限时重新建立；不同论文隔离，恢复任务时使用其记录的分段预算。

停止后可以直接在对话中输入「继续」或「请继续分析」，也可以点击右侧「继续任务」。两者都按当前选中的任务 ID 恢复，保留原问题、文献范围和已完成结果；如有多个任务，在「文献与进度」中选择要继续的任务。模型或连接配置改变时，需要切回原配置后续做。

200 篇是范围上限，不是单次全部塞进模型的上下文；处理时间和服务用量随篇数与长度增长。

## 对话历史

点击顶部历史图标。在对话上右键点击，或点击行末「⋯」，可重命名、置顶、归档 / 取消归档、保存完整会话为笔记、导出或复制为 Markdown。已归档对话在单独的选项卡中查看，仍可打开并继续提问。

“保存完整会话为笔记”保留所有提问、回答、未完成标记和可跳转的原文引用，以及附图和生成图片。图片复制为 Zotero 笔记内嵌附件，不依赖插件缓存。单篇会话附在对应文献下，多篇会话保存为独立笔记并关联文献；没有关联文献时保存到个人文库。

导出支持 Markdown（.md）、JSON、PDF 和 Word（.docx）。「已归档 → 导出全部」按所选格式合并为一个文件；「删除全部」确认后删除归档记录，当前在任一窗口打开的对话会保留。

导出以问题分组，模型名称显示为辅助信息；回答标题统一置于问题层级下方，数字引用对应文末原文。PDF 与 Word 使用紧凑的阅读排版，保留公式、表格和图片。

Markdown 和 JSON 将附图内嵌到文件中，便于独立保存；PDF 与 Word 保留可读排版、图片和引用，Word 公式可编辑。Markdown 的图片显示取决于阅读器是否支持 data URI。导出不含模型连接配置或 API Key。JSON 另保留会话的处理状态与错误记录，其中可能包含本机文件路径；分享前请检查这些诊断信息。

## MinerU 文献解析

在「连接与偏好 → 偏好 → 文献解析」开启 **使用 MinerU 增强解析**，填写官方 API Token 后保存。默认关闭，使用 Zotero 本地文字提取；开启后使用 MinerU 官方云端精准解析。主页不增加读取方式切换。设置用于之后的文献读取，已开始会话保留原有证据。

Token 可在 https://mineru.net/apiManage/token 获取，保存在 Zotero 凭据管理器。高级选项提供 VLM（默认）/ Pipeline、文档语言和 OCR；公式与表格识别始终开启。使用云端 API 无需安装本地 MinerU、Python 或模型。

首次提问才上传需解析的 PDF。按上传、排队、解析与下载阶段显示进度；读取完成后，将正文、结构化表格、公式和按问题选择的图片交给所选模型。原始 PDF 页码保留用于引用。模型不支持图片或能力未知时，需要切换模型，或明确选择仅阅读文字。解析失败不会自动改用 Zotero 或静默跳过文献。

MinerU 提交接口共享每分钟 50 个文件的滚动窗口，结果查询共享每分钟 1,000 次的滚动窗口；跨 Inthes 窗口及普通阅读 / 文献库阅读共用调度。并发数控制在途文献，频率限制控制每分钟新提交文件数，两者独立生效。收到 HTTP 429 后按 `Retry-After`（至少 60 秒）全局等待，同一请求最多重试两次，等待期间可停止。明确的每日上传上限错误不自动重试；每天最多 5,000 个文件由服务端按账户限制，本地不推测剩余额度。Inthes 仅提交 PDF，不提交 HTML。个人 Token 没有公开剩余额度查询接口，设置与读取进度不再显示额度查询或估计余额。

MinerU 和 Zotero 缓存独立，共用偏好中的缓存开关、路径和清理入口。关闭缓存时，新会话可能需要重新上传解析。停止等待会中止客户端上传或请求，已经提交给 MinerU 的服务端任务可能继续；不声称已撤销服务端任务。服务额度、文件上限及数据处理规则以 [MinerU 官方 API 文档](https://mineru.net/apiManage/docs) 为准。

## 模型连接

点击对话框左下角的模型名称，会弹出可搜索的模型列表；首次打开自动获取，之后可刷新。选择立即生效，并按连接保存在本机。设置页同样只提供列表选择，不支持手动输入模型名。连接可先保存端点和 Key，再获取并选择模型；自定义服务须提供相应协议的模型列表接口。旧配置的模型会在获取列表后核对，列表中不存在的模型不能用于新请求。

模型名称右侧可直接选择推理强度，优先采用服务列出的档位，未报告时仅提供已确认的协议与模型档位；能力未知使用模型默认值。生成时显示连接中、思考中及等待秒数、回答中；不显示推理摘要。等待秒数仅在界面显示，不记录耗时。

连接选项卡支持左右方向键切换、Home/End 跳到首尾、Alt+左右方向键调整顺序。切换连接保留当前文献、对话和输入草稿；正在生成时暂时禁用切换和排序。

| 连接 | 配置方式 |
| --- | --- |
| DeepSeek | 已预设 Base URL 和参数，填写 Key 后获取并选择模型 |
| OpenRouter | 已预设 Base URL，填写 Key 后获取并选择模型 |
| OpenAI / Anthropic / Gemini API | 已预设端点，填写 Key 后获取并选择模型 |
| 自定义 | 填写端点和 Key、选择协议，再获取模型列表 |
| ChatGPT 账户 | 通过官方 Codex app-server 登录与推理 |
| Antigravity 账户 | 通过官方 Antigravity CLI（agy）复用本机账户、登录与推理 |

API 支持 OpenAI Chat Completions、Responses、Anthropic Messages、Gemini 原生格式。支持最大输出 token、上下文窗口、自动压缩阈值、推理强度、Temperature、Top P、思考预算、附加 JSON 参数与请求头。按模型能力填写；服务不支持的参数会显示错误。附加 JSON 不允许覆盖消息、模型和其他已由表单生成的字段。

OpenRouter 连接另有「模型提供商（可选）」：留空使用默认路由，填写提供商标识（例如 `deepinfra`）后仅使用该提供商。标识可从 OpenRouter 模型页复制，也支持 `deepinfra/turbo` 这样的具体端点标识；不可用时显示服务端错误。使用官方 [`provider.only` 路由参数](https://openrouter.ai/docs/guides/routing/provider-selection#allowing-only-specific-providers)。

遇到 OpenRouter 的 HTTP 429，界面显示提供商及上游错误原因。请求尚未被接受时最多自动重试两次，优先遵守 `Retry-After`，没有该字段时分别等待 5 秒、10 秒；可点击停止。明确额度耗尽、等待超过 60 秒，以及已经开始返回内容的流不会自动重试。重试始终保留所选模型和指定提供商；指定提供商持续限流时，可手动清空该字段恢复默认路由。参见 [OpenRouter 限流说明](https://openrouter.ai/docs/api_reference/limits)。

Base URL 是协议根路径，例如 `https://api.example.com/v1`，不要追加 `/chat/completions`、`/responses` 或 `/messages`。远程端点须为 HTTPS；localhost 可用 HTTP。

### 账户模式

账户登录使用官方本地组件，不读取浏览器 Cookie。同一 Inthes 会话会复用临时 Codex 会话或 Antigravity 流式进程：首次提交证据和历史，后续仅提交新增问题；更换模型、证据变化或压缩历史后，以有效历史和单份证据重建。中止会中断当前轮次并舍弃该运行时上下文，其他会话和登录保留。运行时会话不跨 Zotero 重启保留，本机对话历史仍按设置保存。可用模型和额度取决于相应 CLI 的账户权限，**不等同于直接调用网页聊天界面的全部功能**。

ChatGPT 连接会自动检测 PATH、Windows 默认 npm 安装目录和本机 Codex 应用中的运行组件。找到组件后自动检查登录状态。找不到时可以手动填写路径，或点击「安装说明」安装后重新检测。如果使用 JavaScript CLI，可把「运行组件路径」设为 `node.exe`，把脚本绝对路径填入启动参数 JSON 数组，例如 `["C:\\tools\\codex\\bin\\codex.js"]`。首次登录需要本人在浏览器完成授权，完成后状态自动更新，ChatGPT 会自动获取模型。账户和 API 连接均可点击「获取模型」，从列表中选择；已获取的列表同时用于对话框左下角的模型选择。

账户模式使用 Inthes 自己的配置目录，避免修改现有 CLI 配置。ChatGPT 连接编辑页可「退出登录」，删除 ChatGPT 连接时也会通过官方接口退出该连接的登录。登录状态检查不发送文献。ChatGPT 关闭 shell、patch 与网页检索并使用只读沙箱；仅论文检索任务按需启用官方联网搜索。

Antigravity 连接自动检测 PATH 及默认安装位置（Windows：`%LOCALAPPDATA%\agy\bin\agy.exe`），复用官方 CLI 保存在系统凭据管理器中的登录。未登录时，可在连接页启动官方浏览器授权；如浏览器给出授权码，在下方输入并完成授权。Inthes 不读取或复制 OAuth token。点击「退出登录」也会退出本机官方 CLI；删除连接仅释放 Inthes 的进程，不退出共享账户。

Antigravity 在隔离目录运行，禁用文件读写、命令与浏览器操作，通过带随机凭据的本机 MCP 入口调用当前会话的文献或导入工具。普通阅读限制使用已提供的文献，禁止网页读取；仅论文检索任务启用原生 `search_web` 与 `read_url_content`，复用同一套 DOI/arXiv 核验、分类导入和去重流程。工具参数定义直接随请求提供，无需读取本地文件。释放会话后停止进程并清理该会话的临时目录，不自动启用额外 AI credits。官方 [流式接口](https://antigravity.google/docs/cli/headless/) 当前仅接收文字，不能粘贴图片；MinerU 文献可明确选择仅阅读文字。图片输入或生图请使用相应支持的连接。

输入框下方使用单行状态栏：占用圆环与已用 / 总上下文、账户 **5h / week 剩余额度**、对应重置时间，以竖线分隔。API 连接显示**可用余额**。重置时间使用本地时间，按前面额度窗口的顺序排列；未提供的时间用 — 表示。状态栏不显示悬浮说明，两种用量独立计算。ChatGPT 通过官方 `account/rateLimits/read` 获取限额，收到服务通知后刷新；Antigravity 通过官方 [`/usage`](https://antigravity.google/docs/cli/commands/usage/) 获取 Gemini 与 Claude/GPT 额度池，按当前模型显示。阅读页打开或对话正在生成时，约每分钟自动刷新；多个窗口合并查询，无需手动刷新。5 小时和周额度按服务实际返回显示，不按订阅名称推断；没有返回的窗口不显示，读取失败标记不可用或上次查询值，不把未知额度当作 100%。

API 连接在同一位置显示**可用余额**，按同样频率自动查询。目前适配 [DeepSeek](https://api-docs.deepseek.com/zh-cn/api/get-user-balance/) 的 `/user/balance`（含赠金）和 [OpenRouter](https://openrouter.ai/docs/api/api-reference/credits/get-remaining-credits) 的 `/api/v1/credits`。OpenRouter 官方当前要求管理 Key；普通推理 Key 无权查询时会提示「当前 Key 无余额查询权限」，不会将 Key 的调用限额冒充现金余额，也不要求用管理 Key 替换推理 Key。[硅基流动公告](https://docs.siliconflow.cn/docs/release-notes/overview) 已停用旧的 `/user/info`，当前不调用该接口。

其他服务可在连接编辑页的「高级参数 → 余额查询（可选）」填写同站点 GET 查询路径、JSON 金额字段（如 `data.balance`）及三位货币代码（如 `CNY`、`USD`）；全部留空使用已适配的官方接口。须按服务文档选择已经以该货币计价的余额字段，当前不支持积分换算、POST 查询或单独的管理凭据。查询使用当前连接的 API Key 与请求头，不发送文献或对话内容，不跟随重定向。未配置接口或没有查询权限时明确提示，修改配置后重新查询。

需要代理时，可在用户的 `~/.codex/.env`（Windows 为 `%USERPROFILE%\.codex\.env`）填写 `HTTP_PROXY`、`HTTPS_PROXY`、`ALL_PROXY`、`NO_PROXY`。如果 Zotero 启动时已有 `CODEX_HOME`，则从该目录读取。组件启动时只导入这些代理变量（支持大小写、引号、`export` 和注释），优先于继承的同名变量，不导入 API Key 或改动账户目录。修改文件后重启 Zotero 生效；文件不存在时沿用原来的网络环境。

账户接口不保证支持任意输出上限，ChatGPT 按模型报告的档位传递推理强度，Antigravity 支持 Low / Medium / High。API 连接可显式设置相应参数。

Gemini API 保持独立；Google 账户订阅通过 Antigravity CLI 接入，不再使用已停用的 Gemini CLI 个人账户通道。

## 文献、历史与笔记

- 优先读取关联 PDF 的文字层，没有 PDF 时使用条目摘要并标明来源范围。未启用 MinerU 时，扫描件需要先 OCR，且不会自动读取 PDF 图片。
- 「XX 处原文可引用」是本地提取的可引用文字片段数，不是上传文件数。发送的是文字证据，不是 PDF 文件。普通提问在预算不足时检索片段并标注覆盖范围。总结入口分段阅读全部来源，再合并证据；较长文献会产生多次请求。
- 同一附件的提取结果保存在本地缓存，依据附件标识、路径、文件大小和修改时间复用；再次新建会话无需重新提取未修改的 PDF。部分文献读取失败时，会列出标题及原因，并等待「重试读取」或「仅使用已读取的文献继续」，不会自动跳过。
- 「连接与偏好 → 偏好」可开启或关闭文献缓存，并自定义缓存文件夹，留空使用 `folio/pdf-cache`。清理仅删除当前目录中的 Inthes 缓存文件及解析结果目录，不删除 PDF、对话、笔记或其他文件。更改位置保留原缓存。关闭缓存后不再读写磁盘缓存，已有缓存保留且仍可手动清理；当前对话中的文献内容不变。本地解析缓存保存文字；MinerU 缓存保存完整返回结果和引用索引，解析模式、语言或 OCR 参数改变后重新解析。
- 页码是 PDF 物理页码。来源编号由插件产生，未匹配到来源的编号不会伪装成可点击引用。
- 在「连接与偏好 → 偏好 → 对话记录保存位置」中，可选择文件夹或填写完整路径，点击「保存位置」生效；留空使用默认位置。默认历史保存在 Zotero 配置目录的 `folio/folio-history.json`，自定义目录同样使用 `folio-history.json`，其中仅包含会话、来源和粘贴的图片。设置单独保存在 `folio/state.json`，修改模型和参数不再重写整份历史。连接配置仍在默认目录，API Key 仍使用 Zotero 凭据管理器。
- 更改位置时合并保留当前对话与目标文件夹中的历史，同一会话采用更新时间较新的记录；清空路径并保存可将历史带回默认位置。原自定义文件夹中的历史文件不会自动删除。「保留对话记录到本地」按新建会话时的开关状态决定是否保存；切换开关不删除已有记录，也不改变当前会话的保存方式。已有历史仍可查看、继续保存和手动删除。
- 自定义位置无法读取时，设置页和历史页会提示错误，并暂停历史写入以避免覆盖旧文件；文件恢复后可再次保存原路径，或设置新位置。测试版仅支持当前存储格式，不提供旧版内联历史、页级引用或 Base64 文献图片的迁移。
- 笔记始终由用户手动保存。单篇生成子笔记，多篇生成独立笔记并关联来源文献。
- 开始对话前自动跟随文库选择或当前 PDF，保留已输入的问题。发送第一条消息后保留当前文献，切换条目、重试和恢复历史都不会改变上下文；点击「＋」新建对话后重新跟随选择。

## 上下文与输入框

默认上下文窗口为 **200,000 token**，自动压缩阈值为 **85%**，可在连接的「参数与高级设置」修改。

新对话显示「上下文剩余 100%」和窗口容量，直到服务首次报告用量。账户连接使用组件报告的上下文占用；其他 API 根据报告的输入与输出计算（有推理用量时扣除），由于服务可能不保留全部输出，标注为约值。没有新用量时保持上次显示。本地仍估算下一次请求的系统提示、文献、历史、草稿和输出预留，仅用于判断自动压缩，不用于更新占用显示。

达到阈值后，在下一次回答前使用当前模型压缩较早对话，尽量保留最近两轮和引用标识。更换到较小窗口时分批压缩；摘要与完整聊天记录分开保存，恢复历史仍可继续对话。压缩会产生额外模型请求，失败或取消时保留原始记录并提示重试。没有可压缩历史时，按问题选择文献片段，或通过总结入口分段读取文献。

这一实现参考 [Codex 的上下文窗口状态](https://github.com/openai/codex/blob/main/codex-rs/core/src/session/context_window.rs)与[历史压缩流程](https://github.com/openai/codex/blob/main/codex-rs/core/src/compact.rs)，使用各协议都能支持的文本摘要，未调用仅适用于特定服务的压缩端点。

引用使用带片段编号的标识，悬浮显示对应原文片段。输入框右上角可向上拖动增高，键盘聚焦后可用上下方向键调整；Inthes 左侧分隔线调整整个侧栏宽度。调整后的宽度与输入框高度会保存；每个窗口分别记住已打开会话的滚动位置，从设置、历史或其他会话返回时恢复。滚动位置保留到该窗口关闭。

## 技术细节

### MinerU 结果缓存

开启文献缓存时，每份 MinerU 结果保留 `result.zip` 原包及 `result/` 下的全部展开文件（含 Markdown、JSON、图片等），索引使用 `folio-mineru-v2-*.json`。图片直接引用结果中的原始文件；读取正文不会加载图片字节，选入模型请求时才读取并编码，最长边超过 2048 像素时仅缩放发送副本。Base64 旧解析缓存不会读取或迁移，下次提问重新解析。关闭缓存时不写入这些解析文件。

保存对话时，需要的文献图片按内容标识保存在对话记录目录的 `folio-history-images/`，多个会话共用同一文件。清理解析缓存不会删除这些历史图片；当前未保存会话的图片保留在内存中。更改历史保存位置会复制对应图片，原位置的记录及图片保留。

硅基流动的 `deepseek-ai/DeepSeek-V4-Flash`、`Pro/deepseek-ai/DeepSeek-V4` 和 `Pro/zai-org/GLM-5.2` 按官方 Chat API 支持高、最高推理档位及关闭思考；其他模型只显示服务明确报告的档位。思考预算支持 128–32768 token，不将预算值伪装成通用推理档位。参考：https://docs.siliconflow.cn/docs/api/chat-completions-post


账户会话延续：启用本地对话记录时，ChatGPT 与 Antigravity 会保存官方会话标识及校验信息。重启 Zotero 或更新插件后，恢复成功只发送新问题；ChatGPT 使用 `thread/resume`，Antigravity 使用 `--conversation` 并保留独立工作目录。原生上下文记录位于默认配置目录的 `folio/accounts`，不随自定义历史目录移动。删除本地会话会清理其关联的官方会话记录。关闭历史保存的新会话及逐篇核查工作会话不启用持久恢复。模型、文献、压缩记录或历史变化时重新发送所需上下文；未完成请求先重建，避免重复执行半途的工具调用。已有旧对话没有官方会话标识，下一次成功回复后才建立检查点。普通 API 继续通过请求携带历史。
